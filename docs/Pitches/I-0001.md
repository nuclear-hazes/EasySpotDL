# Pitch: EasySpotDL

**ID:** I-0001
**Date:** 2026-10-13
**Status:** Promoted → P-0001

---

## Problem

Un grupo de nadadores (hoy 4, probablemente más pronto) tiene audífonos para natación que solo reproducen MP3. Todos pagan streaming (Spotify), pero ningún servicio de streaming entrega archivos MP3: las descargas offline tienen DRM y solo funcionan dentro de la app.

spotDL ya resuelve la parte de fondo: toma una playlist de Spotify, busca cada canción en YouTube y la baja como MP3. Pero es una herramienta de terminal que requiere instalar Python, ffmpeg y deno, y actualizarla seguido porque YouTube la rompe cada tanto. Para personas sin perfil técnico esa barrera es total: hoy simplemente no tienen MP3.

## Appetite

Small batch: unas pocas horas de trabajo, implementado íntegramente con Claude Code. Si algo amenaza con exceder ese presupuesto, se recorta (ver Cut List) en lugar de extender el tiempo.

## Solution

EasySpotDL es una app portable (sin instalador) que envuelve spotDL con una ventana mínima. No es una app nueva para bajar música: todo lo que spotDL ya hace, lo sigue haciendo spotDL.

```
Descargar .zip → descomprimir → doble clic en EasySpotDL
  ├─ primer arranque: descarga el Engine a la carpeta del usuario (requiere internet)
  ├─ cada arranque:
  │    ├─ actualiza el Engine automáticamente, sin preguntar
  │    └─ consulta el Release Channel → si hay versión nueva, muestra el Version Notice con link
  └─ ventana: [ link de Public Playlist ] [ carpeta destino ] [ Descargar ]
               progreso + lista de canciones no encontradas
```

Capacidades clave:
- Preparar el Engine en el primer arranque y mantenerlo actualizado en cada arranque.
- Descargar una Public Playlist como MP3 en la carpeta elegida, con el comportamiento por defecto de spotDL (incluido lo que haga al repetir una playlist ya descargada).
- Mostrar progreso y qué canciones fallaron.
- Avisar (Version Notice) cuando hay una versión nueva de EasySpotDL en el Release Channel.
- Una guía corta para los usuarios: cómo pasar la advertencia de seguridad de macOS / Windows la primera vez.

## Boundaries

### IN Scope
- macOS con Apple Silicon y Windows 11.
- Distribución como archivo comprimido portable; sin instalador, sin tienda de apps.
- Solo Public Playlist como entrada (link pegado por el usuario).
- Actualización automática del Engine en cada arranque.
- Version Notice para EasySpotDL, consultando un Release Channel en GitHub.
- Interfaz de ventana o web local; nunca terminal para el usuario final.

### OUT of Scope
- No se aceptan playlists privadas, canciones guardadas ni ninguna credencial de Spotify del usuario.
- No se cargan archivos en los audífonos ni se organizan por dispositivo.
- No hay "vida útil" ni caducidad de archivos.
- EasySpotDL no se auto-reemplaza: la actualización de la app es manual vía el link del Version Notice.
- Sin firma de código ni notarización (Apple Developer / certificado Windows): se aceptan las advertencias del sistema.
- Sin macOS Intel, Windows 10 ni Linux.
- Sin funciones de descarga propias: calidad, matching, formatos y re-descarga son los de spotDL por defecto.

### Cut List
1. ~~Ventana propia → usar la interfaz web de spotDL~~ — descartado: el spike confirmó que rechaza links de playlist.
2. Lista detallada de canciones no encontradas → mostrar solo el resumen de spotDL.
3. Guía con capturas → guía en texto.
4. Build de Windows automatizado → build manual de Windows en una segunda iteración.

## Risks & Rabbit Holes

- **YouTube rompe el Engine.** yt-dlp se actualiza casi semanalmente para seguir funcionando, pero spotDL fija su versión de yt-dlp; actualizar yt-dlp por fuera de spotDL puede romperlo. Hay que decidir la política sin profundizar de más.
- **Build y prueba de Windows sin una PC Windows.** El build de Windows no se puede verificar en la Mac del autor y la prueba depende de alguien con Windows 11.
- **Spotify sin credenciales.** spotDL usa por defecto un modo sin API oficial para playlists públicas; Spotify viene endureciendo el acceso y este modo puede romperse sin aviso.
- **Licencias.** ffmpeg no debe incluirse dentro del paquete distribuido; se descarga como parte del Engine.
- **Soporte.** Al compartirlo, el autor pasa a ser soporte técnico cuando algo falle. La actualización automática del Engine lo mitiga, no lo elimina.
- **Rabbit hole a evitar:** pulir la ventana, agregar opciones de calidad/formato o intentar mejorar el matching de canciones.

## Spike Results (2026-10-15, macOS Apple Silicon, spotDL 4.5.2)

- Instalación aislada con uv (Python 3.12 + spotDL): ~10 s con buena conexión.
- La Public Playlist se lee sin credenciales: 50 canciones en ~9 s, incluso siendo un "Mix" generado por Spotify.
- Sin deno: 38/50 canciones (12 errores de yt-dlp). Con deno: 49/50. deno es obligatorio en el Engine.
- La búsqueda de letras por defecto choca con límites (HTTP 429) y vuelve todo muy lento; hay que desactivarla.
- Resultado: MP3 ~128 kbps con título, artista y álbum embebidos; ~6 min para 50 canciones; ~3,8 MB por canción.
- La interfaz web de spotDL rechaza links de playlist ("Invalid URL"): el corte #1 no está disponible, EasySpotDL necesita su propia ventana.

## Open Questions

- ¿Quién prueba en Windows 11 y cómo se produce ese build?

## No-Gos

- No reimplementar ninguna lógica de descarga, búsqueda o conversión: eso es del Engine.
- No pedir ni almacenar credenciales de Spotify ni de YouTube.
- No construir un auto-actualizador de EasySpotDL.
- No incluir ffmpeg ni otros binarios de terceros dentro del paquete distribuido.
- No optimizar para escala: es una herramienta para un grupo de amigos.
