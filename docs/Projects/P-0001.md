- [x] `engine.py`: detectar, instalar (`uv tool install spotdl`) y actualizar (`uv tool upgrade spotdl`) el Engine; asegurar deno y ffmpeg vía spotDL; manejo sin internet.
- [x] `__main__.py`: instancia única (archivo de instancia + `/health`), elección de puerto, levantar servidor, abrir navegador.
- [x] `server.py` mínimo: `/` sirve `static/index.html` con título "EasySpotDL", `/health`.
- [x] Launchers `launchers/Abrir EasySpotDL.command` y `launchers/Abrir EasySpotDL.bat` (UV_* hacia carpeta de datos, cuarentena en mac, `chcp 65001` en Windows, mensaje "No cierres esta ventana").
  - El `.bat` no se pudo ejecutar todavía (sin Windows); se valida en `windows_end_to_end` del Scope 3. Ahí también confirmar que spotDL deja `deno.exe` y `ffmpeg.exe` en `%USERPROFILE%\.spotdl`.
  - Limitación conocida (Cut List #3): un segundo doble clic mientras el primer arranque todavía instala o actualiza el Engine levanta un segundo servidor en otro puerto. `uv` serializa las instalaciones simultáneas.
- [x] Tests automatizados para los criterios no manuales.
  - `app/tests/` (unitarios) y `app/tests/test_launch.py` (launcher real contra un HOME desechable; `uv run pytest -m integration`). Requieren el binario `uv` en la raíz del repo.
- [x] Corrección 2026-10-16 (rama `scope-P-0001-1-tool-detection`): en una Mac con ffmpeg de Homebrew, la primera instalación fallaba (`engine_first_install`). spotDL considera instalado un ffmpeg/deno que esté en el PATH, pregunta si lo pisa y, sin terminal para responder, termina con `EOFError`. `_missing_tools` ahora usa el mismo criterio que spotDL (`~/.spotdl` o PATH). Los tests de integración corren con un PATH sin Homebrew, por eso no lo detectaron; lo cubre `test_tools_on_path_are_not_downloaded`.

### Acceptance Criteria
> Copied verbatim from spec.md. Do not modify.

- **launch_opens_browser:** ejecutar `Abrir EasySpotDL.command` en una Mac con la carpeta de datos ya preparada → en ≤ 30 s `GET http://127.0.0.1:<puerto>/` responde 200 con HTML que contiene "EasySpotDL", y la terminal muestra "No cierres esta ventana".
- **launch_port_fallback:** puerto 8765 ocupado por otro proceso → la app escucha en otro puerto libre y abre el navegador en ese puerto.
- **launch_already_running:** EasySpotDL ya corriendo, se ejecuta el launcher de nuevo → no se levanta un segundo servidor; se abre el navegador en la instancia existente.
- **launch_clears_quarantine [manual]:** zip descargado con navegador y descomprimido en Mac, se aprueba el launcher una vez en Configuración → Privacidad y seguridad → `xattr -lr <carpeta>` no muestra `com.apple.quarantine` y no aparecen más advertencias.
- **engine_first_install:** carpeta de datos inexistente, con internet → al terminar el arranque `<datos>/tools` contiene spotDL y `spotdl --version` devuelve `4.x`; deno y ffmpeg están disponibles para spotDL; el log muestra INFO "Engine installed".
- **engine_first_run_offline:** carpeta de datos inexistente, sin red → la terminal muestra "EasySpotDL necesita internet la primera vez" y el proceso termina con código ≠ 0 sin traceback.
- **engine_update_upgrades:** Engine instalado con spotDL `4.5.0` → tras arrancar, `spotdl --version` devuelve la última versión publicada en PyPI.
- **engine_update_offline:** Engine instalado, sin red → la app abre normalmente y el log muestra WARNING "Engine update skipped".

## Scope 2: Ventana de descarga

**Branch:** `scope-P-0001-2-download-ui`
**Status:** `[IN PROGRESS]`
**Depends on:** Scope 1 (servidor, config y Engine)

### Tasks
- [x] `download.py`: validar y limpiar link de Public Playlist; lanzar spotDL como subproceso con `--lyrics` sin proveedores, `--format mp3`, `--output "{list-name}/{artists} - {title}.{output-ext}"` (cwd `~/Music/EasySpotDL`), `--save-errors`, `--simple-tui`; parsing tolerante de progreso; resumen final.
  - Decisiones de implementación (2026-10-16):
    - Reintento automático (aprobado por el autor): si quedan canciones fallidas, se corre spotDL de nuevo, hasta 2 veces; saltea las existentes y reintenta solo las fallidas. Medido: 1.ª pasada 32/50, 2.ª 46/50; en otra corrida 43/50 tras 2 pasadas (por eso se pasó de 1 a 2 reintentos).
    - `--save-file` además de `--save-errors`: da nombre y artista de cada canción. spotDL a veces descarta una canción sin dejar rastro ("Could not get session auth tokens"); esas cuentan como fallidas para que X+Y+Z = M.
    - `COLUMNS=1000` y `PYTHONUNBUFFERED=1` al subproceso: sin eso rich corta las líneas a 80 columnas.
- [x] `server.py`: `POST /download` (400 inválido, 409 en curso, 202 ok), `GET /status` (contrato en `data_model.md`), `POST /open-folder`.
  - `TrustedHostMiddleware` (solo `127.0.0.1` y `localhost`) contra páginas con DNS rebinding.
- [x] `static/index.html`: las tres pantallas de `wireframes.md`, polling a `/status` cada ~2 s.
- [x] Tests automatizados para los criterios no manuales.
  - 2026-10-16, aprobado por el autor: `progress_updates` cuenta los 30 s desde la primera canción completada (spotDL tarda ~30 s en terminar la primera) y `redownload_skips_existing` acepta descargar las que fallaron antes. Ambos criterios se aclararon en `spec.md`.
  - Ejecutado 2026-10-16: 67 unitarios OK; integración (`-m integration`) OK para todos los criterios no manuales. Pendiente: `open_folder [manual]`.

### Acceptance Criteria
> Copied verbatim from spec.md. Do not modify.

- **download_public_playlist:** pegar `https://open.spotify.com/playlist/37i9dQZF1EVHGWrwldPRtj?si=abc` y pulsar Descargar → en `~/Music/EasySpotDL/<nombre de la playlist>/` aparecen ≥ 90 % de las canciones de la playlist como `.mp3` con tags de título y artista.
- **download_no_lyrics:** durante `download_public_playlist` → el log de spotDL no contiene requests a `api.genius.com`.
- **redownload_skips_existing:** repetir `download_public_playlist` → solo se descargan canciones que fallaron en la descarga anterior, el resumen reporta todas las existentes como "ya existían", la carpeta no tiene archivos duplicados.
- **reject_track_url:** pegar `https://open.spotify.com/track/69kOkLUCkxIZYexIgSG8rq` → mensaje "Pegá el link de una playlist de Spotify" y no se lanza spotDL.
- **reject_garbage:** pegar `hola` → mismo mensaje, no se lanza spotDL.
- **single_download_at_a_time:** con una descarga en curso → el botón Descargar está deshabilitado y `POST /download` responde 409.
- **progress_updates:** durante `download_public_playlist` → la página muestra "N de M" con M = total de la playlist, y, a partir de la primera canción completada, N aumenta al menos una vez cada 30 s mientras haya canciones pendientes.
- **summary_shown:** al terminar → la página muestra "Descargadas: X · Ya existían: Y · Fallaron: Z" con X+Y+Z = M, y una lista de Z entradas.
- **open_folder [manual]:** tras `download_public_playlist`, pulsar "Abrir carpeta" → se abre Finder (Mac) / Explorador (Windows) en `~/Music/EasySpotDL/<nombre de la playlist>/`.

> Copied verbatim from spec.md. Do not modify.
